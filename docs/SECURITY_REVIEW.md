# Peridot Sentinel targeted security review

**November 26, 2026 · Session 7 · A6.** One new finding concerns the swap adapter’s approval to the router. The proposed fix passed local tests and has no deployment address. The public demo uses pinned, valueless, exact-transfer tokens. Its evidence supports retaining the current deployment. New asset admission and any funded release require separate review.

The source scope was M4 at `39c0a54`, the base expansion at `81fb457`, the vault sibling at `a48f203`, and both restricted MCP services through `3cb36c5`. The examiner works on the project. This review tested selected properties with local Solidity fixtures and read previously verified public and fork evidence. It does not establish production readiness. ## Reproduce the bounded run

Run from the repository root. The market/expansion fixture loads the pinned core artifacts. Build them first with `forge build --root contracts --offline` on a clean checkout with workspace dependencies installed. The evidence file records full arguments, exit status, tests and result counts for each command. [Captured output](../evidence/session7-security/results.json)

```sh
FOUNDRY_INVARIANT_RUNS=32 FOUNDRY_INVARIANT_DEPTH=24 FOUNDRY_INVARIANT_FAIL_ON_REVERT=true \
  forge test --root contracts/expansion --offline --match-path 'test/review7/*.t.sol' \
  --match-test '^(invariant_authorization|testFuzz_Vault|testNonconforming|testCheckedRouter|testRouterReads)' \
  --fuzz-runs 64 --fuzz-seed 0x77 -v

forge test --root contracts --offline --match-contract MarketIsolationFuzzTest \
  --match-test 'test(FreshTestnet|Fuzz_SecondBook)' --fuzz-runs 64 --fuzz-seed 0x77 -v

# Intentional red control on the pinned adapter. This command must exit 1.
REVIEW7_LEGACY_ADAPTER=true forge test --root contracts/expansion --offline \
  --match-contract RouterApprovalTest --match-test testRouterReadsBackExactApprovalBeforeUse -v
```

Seven new tests passed, including the two 64-case fuzz properties and the 32-run, 768-call invariant. The handler had zero unexpected reverts. Nineteen selected existing Solidity controls and 14 MCP tests passed. The intentional legacy conformance control produced one expected failure.

The state machine seeds an accepted spend, a downstream minimum rejection, an epoch change and a refused post-stop spend before exploration. Actions then replace grants, revoke one operator, change the epoch, advance time or spend. The handler checks the expected contract error on negative paths. Unexpected handler reverts fail the invariant. The fixture has six-decimal, equal-value vault shares and one deposit route. Separate tests cover changed share prices, withdrawal rounding, lending and both-direction swaps. Each bounded result applies to those inputs, profiles and pinned code. No new test signature or authority is needed on 1952.
